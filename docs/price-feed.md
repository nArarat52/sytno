# Собственный каталог цен

В «Мои настройки → Магазины и адреса» укажи город и при необходимости точный адрес. В «Цены и каталоги» вставь прямую HTTPS-ссылку на JSON и нажми «Загрузить цены». Это интерфейс для собственного поставщика данных; он сам не извлекает цены с сайтов магазинов.

```json
{
  "feedVersion": 1,
  "city": "Москва",
  "updatedAt": 1792616400000,
  "offers": [
    {
      "foodId": "rice",
      "store": "PYATEROCHKA",
      "packAmount": 500,
      "priceRoubles": "89.90",
      "address": "",
      "url": "https://5ka.ru/",
      "available": true
    }
  ]
}
```

Цена в примере вымышленная. `updatedAt` нужно заменять временем фактического получения данных в миллисекундах Unix. Дата в будущем более чем на 5 минут не принимается; после суток цена помечается требующей проверки.

Поля:

| Поле | Значение |
|---|---|
| `feedVersion` | Целое `1` |
| `city` | Город из настроек, регистр не важен |
| `updatedAt` | Целое число миллисекунд Unix |
| `foodId` | Идентификатор продукта, уже существующего в приложении |
| `store` | `PYATEROCHKA`, `CHIZHIK`, `MAGNIT`, `PEREKRESTOK` |
| `packAmount` | Целое количество в граммах, миллилитрах или штуках согласно единице продукта; 1–1 000 000 |
| `priceRoubles` | Рубли строкой, точка и не более двух знаков после неё; 0–1 000 000 ₽ |
| `address` | Необязательно. Пустая строка — цена для города; заполненная должна точно совпадать с адресом магазина в настройках |
| `url` | Необязательная HTTPS-ссылка на источник |
| `available` | Необязательный boolean, по умолчанию `true` |

Встроенные идентификаторы: `oats`, `rice`, `buckwheat`, `pasta`, `lentils`, `beans`, `bread`, `chicken`, `turkey`, `tuna`, `fish`, `eggs`, `cottage`, `milk`, `yogurt`, `cheese`, `potato`, `carrot`, `onion`, `cabbage`, `tomato`, `cucumber`, `vegetables`, `tomatoSauce`, `banana`, `apple`, `berries`, `oil`, `sugar`, `salt`, `peanut`, `mushroom`, `tofu`. Для собственного продукта ID можно найти в экспортированной резервной копии.

Не более 5000 предложений и 5 МБ. Дубли, неизвестные продукты, дробный размер упаковки, некорректные цены, другой город и повреждённый JSON отклоняют весь импорт. Текущее сохранение остаётся прежним. Загрузка имеет тайм-ауты и не следует перенаправлениям: ссылка должна сразу возвращать HTTP 200 и JSON.

В расчёте для каждого продукта и магазина используются ручные данные, иначе самые свежие импортированные предложения, иначе встроенные оценки. `available: false` подавляет приблизительное предложение этого магазина. Выбор упаковки минимизирует стоимость покупки целого необходимого количества, а не только цену килограмма. Уже потраченное и ручные покупки включаются в бюджет отдельно.
