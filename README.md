# Сытно

Личное Android-приложение для меню на неделю, бюджета, списка покупок и домашних запасов. Kotlin, Jetpack Compose, Android 8.0+ (API 26), без регистрации. Интерфейс основан на [макете Figma](https://www.figma.com/design/qsnaOCIostON2js9ECKabb?node-id=19-2): Manrope, тёплый фон, зелёные акценты, исходные иконки и фотографии из макета.

## Что работает

- Бюджет и дата начала недели, выбор приёмов пищи.
- Пятёрочка, Чижик, Магнит, Перекрёсток; город и адреса; подбор закупки в одном или двух магазинах.
- Необязательные калории и белок, время активной готовки, повторы блюд.
- Выбор техники: плита, духовка, микроволновка, мультиварка, аэрогриль, блендер и чайник. Допустим выбор без техники.
- Аллергии и нелюбимые продукты; неизвестный состав исключается из планирования при заданных аллергиях.
- 28 встроенных рецептов с пошаговой готовкой. Собственные продукты, рецепты, порции, закрепление и замена блюд с предварительным пересчётом.
- Запасы в граммах, миллилитрах и штуках; килограммы при вводе; сроки годности и отметка «использовать скорее». Просроченные продукты исключаются из доступных запасов для готовки и закупки.
- Список покупок с расчётом целых упаковок; ручные позиции, фактическая цена и количество. Отметка покупки сразу пополняет запасы. Изменение применяет только разницу, отмена возвращает расходы и количество. Использованную покупку нельзя отменить до возврата продуктов.
- После готовки ингредиенты списываются один раз. Отмена готовки возвращает записанное количество, даже если рецепт изменился.
- История недель, перенос запасов, таймер с сохранением времени (без фонового звукового сигнала).
- Автоматическое локальное сохранение, резервная рабочая копия, экспорт и восстановление через системный выбор файла.

## Цены

**Автоматический поиск текущих цен четырёх сетей пока не подключён.** Встроенный каталог содержит явно помеченные приблизительные цены, а не полученные сегодня цены магазинов. Доступ к проверенному endpoint Пятёрочки вернул HTTP 403; подтверждённого общего официального API всех четырёх сетей нет в этой реализации.

Можно вводить цены и наличие вручную, открывать официальные каталоги или подключить собственный источник цен по HTTPS в формате JSON. Формат описан в [docs/price-feed.md](docs/price-feed.md). Ручные цены имеют приоритет над импортом, импорт — над оценками. Источник, адрес и актуальность учитываются; цена старше суток требует проверки. Итог без цены на часть продуктов обозначается как неполный. Пищевая ценность также ориентировочная и рассчитывается по сырым ингредиентам.

## Запуск

Открой эту папку как проект в Android Studio, дождись Gradle Sync и запусти конфигурацию `app` на телефоне или эмуляторе. Нужны SDK Platform 37 и JDK 17 или новее; для текущей среды используется встроенный JBR Android Studio. Gradle Wrapper включён.

```powershell
$env:JAVA_HOME='D:\Android Studio\jbr'
.\gradlew.bat :app:assembleDebug
```

Результат обычной сборки: `app/build/outputs/apk/debug/app-debug.apk`. APK, локальные кэши, настройки IDE и данные эмуляторов не включены в репозиторий. Debug APK подписывается локальным отладочным ключом. Для обновления с сохранением данных сохраняй тот же ключ подписи. Перед удалением приложения сохрани резервную копию: удаление Android-приложения удаляет его локальные данные.

## Проверки

```powershell
.\gradlew.bat :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease
```

`core` — независимая логика подбора, бюджета, запасов, импорта и хранения. `app` — нативный интерфейс и сохранение через ViewModel. UI-тесты используют Robolectric с нативной графикой Android API 35 и нажатиями на реальные Compose-компоненты. Отчёты: `core/build/reports/tests/test`, `app/build/reports/tests/testDebugUnitTest`; снимки экранов: `app/build/reports/screenshots`.

Подробный результат проверки и ограничения среды — в [docs/testing.md](docs/testing.md).

Итог: 90 тестов пройдены (75 логики, 15 интерфейса); Lint без ошибок; Debug и Release успешно собраны. Снимки интерфейса просмотрены вручную. Физический телефон в этой среде не подключался.

Ориентиры температуры готовности птицы и рыбы в инструкциях сверены с [таблицей USDA FSIS](https://www.fsis.usda.gov/food-safety/safe-food-handling-and-preparation/food-safety-basics/safe-temperature-chart). Лицензии Manrope и Lucide включены в `docs/licenses` и в ресурсы APK.

Данные приложения находятся во внутреннем файле `files/sytno-state.json`; резервная рабочая копия — рядом с расширением `.bak`. Запись проверяется и завершается до показа успешного действия. Повреждённые файлы сохраняются для восстановления. Облачной синхронизации и аналитики нет. Интернет используется только по запросу для загрузки указанного каталога или открытия сайта магазина.

## Структура

- `app/` — интерфейс Compose, шрифт и исходные визуальные материалы.
- `core/` — модели, планировщик, складские операции, цены, сериализация и тесты.
- `design/sytno/` — исходники и аудит дизайна Figma.
- `docs/` — формат каталога и результаты тестирования.
- `.local/` — игнорируемые локальные инструменты, временные файлы и тестовый AVD.

Локальные кэши и тестовые эмуляторы не требуются для клонирования проекта: зависимости загружаются Gradle, устройство для запуска выбирается в Android Studio.
